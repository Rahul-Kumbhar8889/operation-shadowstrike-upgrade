# Operations proof asset provenance

The building `operations.glb` is original geometry generated by
`scripts/build-operations.py` in this repository. Its signage, weathering overlay,
edge masks and local sky-reflection approximation are original procedural artwork.
No proprietary Project IGI or paid assets are included.

The following texture sets are downloaded from Poly Haven and redistributed under
**CC0 1.0 Universal**. Attribution is not required; these credits are retained for
provenance. Commercial use, modification and redistribution are permitted by the
publisher's asset license.

Publisher license: https://polyhaven.com/license

CC0 legal text: https://creativecommons.org/publicdomain/zero/1.0/legalcode

The official publisher license-page source was saved as
`polyhaven-license-source.json`; its upstream source is
https://github.com/Poly-Haven/polyhaven.com/blob/master/public/locales/en/license.json.

`materials.json` records each downloaded map URL, the publisher's MD5, the checked
original SHA-256 and each optimized file's SHA-256. Source maps are obtained using
Poly Haven's file API. Publisher MD5 values are verified before processing. The
preparation client uses a unique User-Agent as required by the API service terms:
https://github.com/Poly-Haven/Public-API/blob/master/ToS.md.
The running game makes **no Poly Haven API/CDN requests**.

All four sets include diffuse, OpenGL normal, roughness and AO maps. Metal Plate
also supplies a metallic map. Optimized albedo is WebP (quality 90); normal maps
use lossless WebP; linear AO/roughness/metallic values are packed into RGB PNG.
Resolution is capped at 1024². No height/displacement map changes world geometry.

Rebuild geometry from the repository root:

    blender -b --python scripts/build-operations.py

Refresh maps (requires Python 3, Pillow, and network access to api.polyhaven.com
and dl.polyhaven.org):

    python3 scripts/fetch-operations-materials.py

Refresh source/license evidence if the publisher's terms change. The model export
uses five material batches; Draco is not enabled or required. Blender may log
that its optional Draco library is absent, but ordinary GLB export succeeds.
